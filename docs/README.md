# docs

Planleggingsdokumenter for arbeid i sigill-dotnet. Samme mappestruktur som
de andre Sigill-repoene: `epics/` og `tasks/` med statusmappene
`1-backlog`, `2-in-progress`, `3-completed` og `4-wont-fix`. En fil flyttes
mellom statusmappene i den PR-en som endrer statusen.

Spesifikasjonen bor i `spec/`, ikke her. Dokumentene her beskriver hva som
skal bygges og hvorfor; `spec/` beskriver hva som er normativt.
